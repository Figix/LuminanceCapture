# LuminanceCapture.Tests

## 담당 범위
Core 로직의 xUnit 단위 테스트: 휘도(`LuminanceTests`), 파일명(`PairNameAllocatorTests`), 설정(`SettingsTests`), 흑백 필터 상태(`GrayscaleFilterTests`), 단축키 해석(`HotkeyParserTests`), 캡처 서비스·저장(`CaptureServiceTests`), 앱 보조 로직(`AppShellTests`: 자동 실행, 단일 실행, 단축키 입력·적용, 로그).

## 이 모듈의 범위가 아닌 것
실제 화면 효과, 실제 화면 캡처, 실제 단축키 등록, 창·트레이 모양. 이런 동작은 실행 파일을 직접 구동해 확인한다.

## 불변식
- 테스트는 실제 `HKCU\...\Run` 키, 사용자 설정 파일, 화면 색상 효과를 건드리지 않는다. 레지스트리는 임시 키 경로, 설정은 임시 파일, 화면 효과와 캡처는 가짜 구현을 쓴다.
- 파일 시스템 테스트는 테스트마다 고유한 임시 폴더를 쓰고 끝나면 지운다.
- 테스트는 Core만 참조한다(`net10.0-windows10.0.22621.0`). 빈 테스트 프로젝트는 "테스트 없음"으로 실패한다.

## 테스트 지침
새 Core 동작에는 먼저 실패하는 테스트를 쓴다. 필수 경계: 휘도 기대값과 R=G=B 불변, 행렬·버퍼 변환 일치, 파일명 충돌(컬러만/흑백만/여러 번), 설정 부분 손상, 쌍 저장 원자성, 연속 요청 순서와 무손실, 단축키 거부 규칙(수정키 없음·같은 조합·알 수 없는 키).
