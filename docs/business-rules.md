# 도메인 규칙

## 휘도 정의

`Y = 0.2126·R + 0.7152·G + 0.0722·B` (Rec.709 비율). R, G, B는 화면에 보이는 감마 인코딩된 sRGB 값(0–255)이고 선형광으로 바꾸지 않고 그대로 계산한다. 결과 픽셀은 R=G=B=Y이며 Y는 반올림(0.5 올림) 후 0–255로 제한한다. 알파는 보존한다. 예: 순수 빨강(255,0,0) → 54, 순수 초록 → 182, 순수 파랑 → 18, 흰색 → 255, 검정 → 0, 이미 R=G=B인 픽셀은 값이 변하지 않는다.
- 이 정의는 화면 흑백(색상 변환 행렬)과 저장되는 흑백 파일이 공유한다. 두 곳이 서로 다른 계수나 선형광 변환을 쓰면 "화면에서 본 톤 = 파일 톤"이 깨진다. 그래서 한쪽만 바꾸지 않는다.

## 흑백 필터

- 상태는 켜짐/꺼짐 두 가지. 모든 연결 모니터에 동시에 적용된다. 모니터별 적용은 없다.
- 프로그램이 시작되면 항상 꺼짐이다. 켜짐 상태는 저장하지도 복원하지도 않는다(부팅 직후 화면이 갑자기 흑백이 되는 것을 막기 위함).
- 프로그램이 정상 종료하든 강제 종료·크래시하든 화면은 컬러로 돌아온다(효과가 프로세스 수명에 묶여 있다). 정상 종료 시에는 명시적으로 단위 행렬을 적용한 뒤 해제한다.
- 절전 복귀, 세션 잠금 해제, 화면 구성 변경 뒤에는 켜짐 상태일 때 효과를 다시 적용한다.
- 효과 적용에 실패하면 상태는 바뀌지 않고 `Changed`도 발생하지 않는다. 사용자에게는 "흑백 전환에 실패했습니다." 알림이 간다.

## 캡처

- 입력 하나 = 쌍 하나(컬러 1 + 흑백 1). 단축키만 있고 한쪽만 저장하는 입력은 없다. 단, 설정 창·트레이의 "지금 캡처"도 같은 쌍 캡처다.
- 대상은 입력 순간 마우스 포인터가 있는 모니터 한 대의 전체 화면이다. 모니터는 `Request()` 호출 순간 확정되며 큐에서 기다리는 동안 포인터가 움직여도 바뀌지 않는다. 해상도는 DPI 배율과 무관한 그 모니터의 물리 픽셀 전체다.
- 마우스 포인터는 이미지에 그리지 않는다. 프로그램의 알림창은 이미지에 들어가지 않는다(프레임을 먼저 얻은 뒤 알림을 띄우고, 알림 창은 화면 캡처 제외 속성도 가진다). 설정 창은 제외하지 않으므로 화면에 떠 있으면 그대로 찍힌다.
- 컬러 파일은 필터 켜짐 여부와 무관하게 실제 컬러다. 흑백 파일은 그 컬러 바이트에서 휘도 정의로 계산한다. 필터가 적용된 화면 픽셀로 흑백을 만들지 않는다.
- 입력은 모두 처리한다. 연타해도 무시·간격 제한 없이 누른 만큼 쌍이 만들어지고 요청 순서대로 저장된다.
- 검은 화면(보호된 콘텐츠 등)은 감지하지 않고 그대로 저장한다.

## 저장

- 모든 파일은 하나의 평면 폴더에 쌓인다(묶음·날짜·하위 폴더 없음). 형식은 PNG 무손실, 흑백 파일도 R=G=B인 RGB 채널 PNG(알파 없음).
- 파일명은 요청 시각 기준 `yyyy-MM-dd_HHmmss_color.png`와 `yyyy-MM-dd_HHmmss_gray.png`. 한 쌍은 같은 시각 문자열을 공유한다. 두 이름 중 하나라도 이미 있으면 시각 뒤에 `_2`, `_3`…을 붙여(`2026-10-26_153012_2_color.png`) 쌍 전체가 새 이름을 쓴다. 기존 파일은 덮어쓰지 않는다.
- 기본 폴더는 사용자 사진 폴더 아래 `LuminanceCapture`이며 설정에서 바꾼다. 폴더가 없으면 만든다. 폴더는 캡처마다 그 시점의 설정으로 계산한다.
- 쌍 단위 원자성: 두 파일을 같은 폴더의 임시 파일로 쓰고 이름을 바꿔 들여놓는다. 어느 단계든 실패하면 임시 파일과 이미 들여놓은 쪽을 지워 반쪽 파일이 남지 않게 하고 실패를 알린다. 실패 사유는 쓰기 불가 폴더, 디스크 가득, 그 외 저장 실패로 구분한다.

## 설정과 단축키

- 설정 필드: 흑백 단축키(기본 `Ctrl+Alt+F9`), 캡처 단축키(기본 `Ctrl+Alt+F10`), 저장 폴더(없으면 기본 폴더), 자동 실행(기본 켜짐), 캡처 소리(기본 꺼짐).
- 단축키 표기 규칙: 수정키(Ctrl/Alt/Shift/Win) 하나 이상 + 일반 키 정확히 하나. 수정키 없는 단독 키, 키 두 개 이상, 알 수 없는 키 이름, 빈 문자열은 거부한다. 두 단축키가 같은 조합이면(표기 순서가 달라도) 거부한다.
- 변경이 거부되거나 다른 프로그램이 이미 쓰는 조합이라 등록에 실패하면 설정은 저장되지 않고 이전 단축키가 계속 동작한다. 시작할 때 저장된 단축키 등록에 실패하면 어느 쪽인지 설정 창에 표시하고 창을 연다.
- 설정 파일이 일부만 깨졌으면 깨진 필드만 기본값으로 대체하고 나머지는 유지한다. 파일이 없거나 JSON 전체가 깨졌으면 모두 기본값이다.

## 실행

- 자동 실행이 켜져 있으면 로그인 시 `--background`로 시작해 창 없이 트레이에만 뜬다. 수동 실행(인자 없음)은 설정 창을 보여 준다.
- 창의 닫기(X)는 창만 숨기고 프로그램과 단축키는 계속 동작한다. 완전 종료는 트레이 메뉴 "종료"뿐이다.
- 이미 실행 중일 때 다시 실행하면 새 인스턴스는 곧바로 종료하고 기존 창을 앞으로 가져온다(숨겨져 있으면 보여 준다).
