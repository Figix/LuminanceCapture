# 풀지 못한 문제

## 설치 파일을 컴파일하지 못함
- 조건: `tools/build-installer.ps1` 실행 시 `ISCC.exe`가 없다. 증상: 종료 코드 2, `dist/publish`만 생기고 설치 파일은 없음.
- 영향: 설치→시작 메뉴 검색 실행→제거 흐름이 한 번도 실행되지 않았다. 스크립트 문법 오류가 있어도 아직 드러나지 않는다.
- 지금 풀 수 없는 이유: Inno Setup 6을 내려받아 설치해야 하며 사용자 승인이 필요하다.
- 접근: Inno Setup 6 설치 후 스크립트를 다시 실행하고 설치·제거를 실제로 해 본다.

## 캡처 실패 알림에 영어 사유가 섞임
- 조건: 캡처 저장이 실패하면 토스트가 한국어 접두어("캡처에 실패했습니다: ") 뒤에 Core의 영어 오류 문장을 그대로 붙인다.
- 영향: 오류 알림이 한영 혼합으로 보인다. 동작에는 영향 없음.
- 지금 풀지 않은 이유: Core 오류 사유를 코드(디스크 가득/쓰기 불가/캡처 실패 등)로 분리해 App이 한국어로 옮기는 변경이 필요해 이번 범위를 넘는다.

## 트레이 컨텍스트 메뉴는 캡처에서 제외되지 않음
- 조건: 트레이 메뉴(WinForms `ContextMenuStrip`)가 열린 채 캡처 단축키를 누르면 메뉴가 이미지에 찍힌다.
- 영향: 메뉴를 연 채 단축키를 누르는 드문 경우에만 해당. 토스트와 달리 화면 캡처 제외 속성을 줄 수 없는 컨트롤이다.
- 지금 풀지 않은 이유: 메뉴를 WPF 창으로 다시 만들어야 해서 비용이 크고 사용 빈도가 낮다.

## WGC 장치 손실을 복구하지 않음
- 조건: 그래픽 드라이버 재시작 등으로 D3D 장치가 사라지면 이후 캡처가 계속 실패한다.
- 영향: 프로그램을 재시작해야 복구된다. 실패 사유는 오류 알림으로 보인다.
- 지금 풀지 않은 이유: 재현 조건이 드물고 이번 범위에 장치 복구 요구가 없다.
