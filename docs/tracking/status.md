# 진행 상태

## 완료 (빌드·자동 테스트 통과: `dotnet build` 0, `dotnet test` 87개 통과)

- 휘도 정의·행렬·버퍼 변환, 쌍 파일명 할당, 설정 저장소 — 단위 테스트로 검증.
- 흑백 필터(Magnification), 전역 단축키 해석·검증·변경 로직, 자동 실행 관리, 단일 실행 — 가짜 API로 단위 테스트 검증.
- 캡처 서비스(WGC 획득, 쌍 원자 저장, 직렬 큐) — 단위 테스트 + 실제 화면 실험으로 검증: 필터가 켜진 상태에서 빨간 창을 찍으면 컬러 파일 (255,0,0), 흑백 파일 (54,54,54), 이미지 1920x1080, 포인터 영역 오염 없음.
- 앱(트레이, 설정 창, 토스트, 서비스 조립) — 빌드한 실행 파일을 실제로 구동해 확인: `--background` 시작 시 창 없음, 흑백 단축키 전환·복귀, 캡처 단축키로 쌍 생성, 두 번째 실행이 기존 창을 앞으로 가져옴, 창 닫기는 트레이 숨김, 흑백 켠 채 강제 종료하면 컬러 복귀.
- 게시(win-x64 self-contained)된 실행 파일이 시작되는 것을 확인.

## 빌드됨, 사람 확인 필요 (자동화하지 못함)

- 설정 창 모양과 한국어 문구, 트레이 아이콘 두 종류(16px 식별성), 트레이 메뉴와 더블클릭, 폴더 선택 대화상자, 토스트 모양·위치(포인터가 있는 모니터 작업 영역 오른쪽 아래, 성공 1.5초 / 오류 3.5초), 캡처 소리.
- 설정 창 텍스트 상자에 단축키를 직접 눌러 입력하는 경로와 인라인 오류 표시(로직은 단위 테스트됨).
- 실제 자동 실행 경로: 첫 실행 등록, 체크박스 토글, 로그인 시 `--background` 시작(테스트는 임시 레지스트리 키만 사용).
- 듀얼 모니터·DPI가 다른 모니터에서의 캡처 대상 선택과 토스트 위치(캡처는 단일 모니터 1920x1080에서만 실측).

## 남음

- 설치 파일 컴파일: 스크립트(`installer/LuminanceCapture.iss`)와 빌드 스크립트는 작성됨. Inno Setup이 이 PC에 없어 설치 파일은 아직 만들지 못했고 설치→검색 실행→제거 흐름은 미검증.
- 범위 밖으로 둔 기능: 모니터별 흑백 적용, 영역·활성 창 캡처, 명암 단계(포스터라이즈) 보기, 클립보드 복사, 일정 간격 자동 캡처, 캡처 갤러리, HDR 디스플레이 대응.
