# 0002 화면 흑백은 전체 화면 색상 변환(Magnification)으로

## 배경
이 도구의 존재 이유는 작업 프로그램 바깥에서, 어떤 프로그램 위에서든 같은 단축키로 화면 전체를 흑백으로 보는 것이다.

## 결정
Magnification API의 `MagSetFullscreenColorEffect`로 5x5 색상 행렬을 건다. 끄기는 단위 행렬 적용, 종료 시 해제.

## 검토한 대안
- 화면 전체를 덮는 오버레이 창에 흑백 셰이더: 창이 입력과 포커스를 가로채거나 클릭 통과 처리가 필요하고, 전체 화면 앱·모니터 구성 변화에서 깨지기 쉽다. 기각.
- 작업 프로그램별 흑백 기능 연동: 프로그램마다 달라 목적과 반대다.
- 파이썬 구현: 화면 전체 실시간 처리가 무겁고 불안정해 사용자가 C#을 선택했다.

## 결과
- 모든 모니터에 한꺼번에 적용되고 모니터별 적용은 불가능하다.
- 변환은 감마 인코딩 값 위에서 일어나므로 휘도 정의도 감마 인코딩 값 공간에 있어야 한다.
- 효과가 프로세스 수명에 묶여 강제 종료 시 자동으로 컬러로 복귀한다. 반대로 프로세스가 살아 있는 동안은 외부에서 끌 수 없다.
- 절전 복귀 등에서 효과가 사라질 수 있어 재적용 로직이 필요하다.
