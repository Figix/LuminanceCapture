# 0003 휘도는 Rec.709 계수를 감마 인코딩 값에 직접 적용

## 배경
사용자는 눈의 밝기 인식에 기반한 흑백을 원했고, 화면에서 본 톤과 저장된 흑백 파일의 톤이 똑같아야 한다고 선택했다.

## 결정
`Y = 0.2126R + 0.7152G + 0.0722B`를 화면에 보이는 감마 인코딩 sRGB 값에 선형화 없이 적용한다. 화면 색상 변환 행렬과 파일 변환이 같은 계수 상수를 공유한다.

## 검토한 대안
- 선형광으로 바꿔 계산한 정밀한 밝기: 파일은 더 정확하지만 화면 색상 변환은 감마 값 위에서만 동작해 두 결과에 미세한 톤 차이가 생긴다. 사용자가 "똑같이 맞춤"을 선택해 기각.
- Rec.601 계수(0.299/0.587/0.114): 오래된 표준이며 sRGB 원색과 맞는 Rec.709를 택했다. 두 값의 차이는 크지 않지만 계수를 바꾸면 모든 톤이 달라진다.

## 결과
- 순수 빨강은 54, 초록은 182, 파랑은 18로 변환된다(테스트가 고정).
- 계수는 한 곳(`Luminance`)에만 있어야 한다. 한쪽만 선형광으로 바꾸면 화면과 파일의 톤이 어긋난다.
- 물리적으로 정확한 광량 흑백은 이 도구가 제공하지 않는다.
