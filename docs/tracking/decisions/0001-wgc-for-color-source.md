# 0001 컬러 원본은 Windows.Graphics.Capture로 획득

## 배경
흑백 필터를 켠 채로도 캡처 한 쌍의 컬러 파일은 실제 컬러여야 한다. 윈도우 11, 모니터 2대에서 순수 빨강(255,0,0) 창을 띄우고 필터를 켠 뒤 방법별로 읽어 비교했다.

## 결정
컬러 프레임은 Windows.Graphics.Capture(모니터 대상, 커서·테두리 끔)로 얻는다. 흑백 파일은 그 컬러 바이트에서 소프트웨어로 계산한다.

## 검토한 대안
- GDI `CopyFromScreen`: 필터가 적용된 (54,54,54)를 반환 — 컬러 원본이 불가능해 기각.
- DXGI Desktop Duplication: 같은 영역에서 빨강 0개, 회색(54) 5815개 — 필터 적용 후 출력이라 기각.
- 캡처 순간 필터를 잠깐 풀었다가 복구: 화면이 약 0.1초 깜빡이고 연타 시 반복되어 작업을 방해한다. 위 방식이 가능하다는 것이 확인되어 불필요해졌다.

## 결과
- 윈도우 11(`10.0.22000+`) 전용 API에 의존한다(`IsBorderRequired`). 윈도우 10 지원은 불가능해졌다.
- Direct3D 장치가 필요해 Vortice 패키지에 의존하고, 장치 손실 복구가 없다.
- 컬러 획득 경로를 GDI/DXGI로 "단순화"하면 필터가 켜진 캡처가 조용히 회색이 된다.
