# 결정 기록

| 번호 | 결정 | 요약 |
|---|---|---|
| 0001 | 컬러 원본은 Windows.Graphics.Capture로 획득 | 흑백 필터가 켜져 있어도 GDI·화면 복제는 필터 적용 픽셀을 준다. 깜빡임 없이 실제 컬러를 주는 것은 이것뿐 |
| 0002 | 화면 흑백은 전체 화면 색상 변환(Magnification)으로 | 오버레이 창 대신 합성 단계에서 거는 방식 |
| 0003 | 휘도는 Rec.709 계수를 감마 인코딩 값에 직접 적용 | 화면 변환과 저장 파일 톤을 같게 맞추려는 선택. 선형광 계산은 기각 |
