# 보안

## 보호 대상

- 사용자의 화면 내용. 캡처 이미지에는 작업 중인 문서·메신저·계정 정보가 찍힐 수 있다. 이미지는 사용자가 정한 로컬 폴더에 암호화 없이 일반 PNG로 저장된다.
- 사용자 계정 환경: 시작 프로그램 목록(HKCU Run), 설정 파일, 로그.

## 허용되는 동작

- 사용자 권한(비관리자)으로 실행되고 설치된다. 설치는 사용자 단위 폴더, 시작 메뉴 항목, HKCU Run 값 하나만 만든다.
- 화면 전체 색상 변환(Magnification), 화면 캡처(Windows.Graphics.Capture), 전역 단축키 등록.
- 쓰기 위치: 사용자가 정한 저장 폴더(PNG와 임시 파일), `%AppData%\LuminanceCapture\settings.json`, `%LocalAppData%\LuminanceCapture\log.txt`, `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`의 `LuminanceCapture` 값.

## 금지되는 동작

- 네트워크 통신(업로드, 텔레메트리, 업데이트 확인 포함). 캡처 이미지는 로컬 폴더 밖으로 나가지 않는다.
- 관리자 권한 요구, 서비스·예약 작업 등록, 다른 레지스트리 키 쓰기.
- 로그에 화면 내용·이미지 데이터를 남기는 것. 로그에는 오류 메시지와 예외만 쓴다.
- 기존 사용자 파일 덮어쓰기(캡처 파일명 충돌 시 새 이름을 쓴다).

## 인증·권한·감사

- 계정, 로그인, 권한 구분 없음(단일 사용자 로컬 도구). 감사 대상 이벤트 없음.
- 다른 프로세스가 이미 쓰는 전역 단축키 조합은 등록이 거부되고 사용자에게 어떤 단축키가 실패했는지 표시된다. 조용히 덮어쓰지 않는다.

## 비밀·민감 데이터

- 저장된 캡처 이미지가 유일한 민감 데이터이며 보존 책임은 사용자에게 있다. 제거(언인스톨)는 이미지와 설정 파일을 지우지 않는다.
